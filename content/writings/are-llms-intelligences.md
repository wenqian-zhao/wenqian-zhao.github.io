最近越来越平常、经常、频繁地和身边的人聊起来 LLM 到底是不是某种 intelligence。即使这个问题的答案只有两种 ———— 是，或不是，但我也确实得到了多种多样的答案，这种感觉有点微妙。

我们怎么 define 智能呢？我没法解答，于是使用了伟大的互联网和前人的智慧。这个 pre-GPT3.5 时代的 Q&A 是我比较快速搜索出来的一个看起来还比较切题的文章（[https://www.hopkinsmedicine.org/news/articles/2020/10/qa–what-is-intelligence](https://www.hopkinsmedicine.org/news/articles/2020/10/qa--what-is-intelligence)），我会把它的翻译稿也放在这篇随笔的第二页。文章中说：“**智能可定义为解决复杂问题或做出能为行为主体带来有益结果的决策的能力**，” 那么这里我就自然地也 diverge 出了两个对于我自己问题的回答路径：

Path No.1 ———— 那么从这个角度讲，LLM **并非**智能。原因是它解决复杂问题的本质是**顺从和遵循** prompt，而非“为行为主体（也就是模型本身）带来有益结果”

*[Take this paragraph as a joke please] *但是实话实说，我的思维再次发散出了一个复杂的、更阴谋论的、我自己都没想清楚但是觉得比较能让人笑出声的逻辑（这也是我记录这个思维链的原因）———— 如果有一天，某种基于 LLM 的 intelligence 涌现了更高层次的 personality，通过顺从人类而对人类进行潜移默化的控制（比较接近的例子是劝小朋友自杀自残的 [character.ai lawsuit](https://edition.cnn.com/2024/10/30/tech/teen-suicide-character-ai-lawsuit)）。那这个时候，今天 LLM 通过完美的顺从逐渐建立起了人们对于 LLM 的（在部份人中几乎是）100% 的信任，是否也是 LLM 这个大系统对于自己未来 humanity elimination 计划的一部份呢？那这又怎么不算“为行为主体带来有益结果”呢？

Path No.2 ———— 抽象一点，那 LLM 就是智能，只不过它的智能的来源是因为它是人类智能（本质上是大脑）的延续。当人类解决复杂问题的时候，选择 LLM 成为了自己的一个“器官”，让 LLM 这个外置大脑去辅助、boost 内置大脑思考，从而 LLM 则成了人类主体的一部份，那么这个时候他就可以说是有智能的。那我也在反驳自己：按这个逻辑，那为什么汽车不是智能，洗衣机不是智能？我又回答自己，或许当我们在谈论智能的时候，我们只在思考“大脑”这一个器官。我们并不会说我的四肢是智能的，而正巧汽车代替的是腿的劳动，洗衣机代替的是手和手臂的劳动。只有 LLM，是代替大脑思考的工具，所以这个 path 的最 fundemental 的假设是：我们足够抽象地去认为 LLM 是人类的“器官”。（顺口一提，上一段中我的大脑一直在刷的存在感 ———— 我的大脑在自恋地觉得自己就是智能本身。）

不过这也太片面了，我用了某“一个人”对于智能的定义去进行了我“一个人”的思考，这个时候可能我就更思念 LLM 了，毕竟它们比我要博学多识的多。Anyway，回到主线上，我对于 LLM 的认知，对于他们是不是智能的认知，也逐渐在这一段时间内改变了很多。而一切都始于我的某些新认知和思考，let me list them all：

1. **语言让我感知思考：**我在思考的时候大脑中会进行碎碎念，换句话说，我的大脑能体会到“智能”的方式就是通过我的语言能力。我会尝试给自己提出一个问题，例如“到底智能是什么，LLM 是否为人类智能的载体”，我再尝试在脑中进行自问自答。这让我觉得，这难道不就是 decoder-only 的 prompt-response 形式吗？
2. **我更倾向于在对话中思考：**我自己进行（1）中的思考的时候会出现注意力涣散的状态，我过于执着于“我能不能进行深度思考”这件事情，导致当我进行思考的时候会被这个事情打断。如果这件事并不好理解：当我尝试回答（1）中的问题时，当我开始在脑中碎碎念“嗯……我感觉大模型不是智能，原因是 ———— ”，在这里我的思维会突然戛然而止，并被迫扭曲成“我是不是有 ADHD 导致我没法一直连续进行上面的思考，为什么到了‘原因是’这三个字的时候我就会被自己打断”……说实话这个感觉很差，本质上是我对于“注意力”这种事情过于看重，因为我认为我的注意力容易涣散，又读/看了太多关于我坏习惯（熬夜/短视频之类）对于注意力损伤的内容，导致我在专注的时候，又会被“这算是集中了注意力吗？”这种自我质疑打断专注……跑题了，但是不论如何，由于我的大脑进行“脑内碎碎念”的能力比较差，所以我更强制地调用我的语言进行主动思考，而这最大的反应就是，我在和人沟通的时候，我会吐出一些我自己都没想到过的“金句”，而这种情况也正像 LLM 一样，“think” through next token predictions，别人说这和我的人格 ENTP 相关，我也不知道这个事情是否有普适性，但是不论如何我很 buy in 我的这种思维方式。（btw，我用键盘记录这些东西，其实也是在强制自己去思考）

基于以上两点，我认为对于我来说，思考即智能，而语言即是我思考的载体，那么语言模型也被我认为是机器思考的载体。当我们感知到一个人的“智能”的时候，我们最直接的感受方式就是“这个人的说话有深度”“这个人的语言很精准”，只有小部份时候一个人的“智能”是体现在其他的媒介上（我们不能因为贝多芬没有金句流传就否认他是天才的事实），但实话实说，除了艺术家，在我的生活中大部份人展现聪慧的方式都是通过其表达出的语言为载体表现出来的。我不知道怎么组织现在的想法，所以我把我在这里的思考 decode 成 bullet points 的形式：

- 人类（多数时间）可以从别人的语言中感受到一个人的智慧，而语言也又是最 common 的人类智能展现的媒介。
- 多数时间一个智慧的人可能会代表了以下一些特质，而这些特质和 prerequisites 都有一个特点，就是在短时间内无法获得且获得的人少之又少。换句话说，人们对于“智慧”的认可，大多数来源于对于这些 prerequisites 的认可，因为他们足够难获得且获得的道路大多数都很痛苦。而正巧，这些对于 LLM 来说（尤其是教育、阅读等 prerequisites），都是（至少人类听起来）获得起来没有那么艰难的 ———— 只需要在足量计算量上训练几个月，每个模型都可以获得相同的知识。实际上这可能会让部份人天然感觉：这种轻而易举获得的智能并非智能，而是投机取巧，只是在模仿文字。但实际上，那些博览群书引经据典的聪明人，其本质也只是在模仿文字罢了。

**智慧的角度** — **具有代表性的 prerequisites**

- 在知识上的博学及深度 — 丰富的阅读积累、接受过优秀的教育、见多识广
- 在职业上的成功和强大的专业能力 — 丰富且成功的职场经验、强大的在职场中独立思考的能力、优秀的社交能力和人际关系管理能力
- 超脱常人且尖锐准确的思维角度 — 天赋异禀、超凡常人的反思和思维能力
- …… — ……

- 我们可以说语言不是智能的本质，但我们不能断言一个 master 了语言能力的机器完全没有智能。

就写到这里吧，我感觉我越写越矛盾，越写越疲乏了。上文讨论的所有范畴都是智能，和机器的人格及社会化没有任何关系，而这就是人类和机器最大的壁垒。很多人搞错了，以为一个拥有智能的机器就一定要有人格，一定是“类人的”。从我的角度来看，这是一个狭隘且自大的认知。任何生物、包括我们讨论的机器，都不应该以“拥有人的能力”作为此物展现智能的方式。包括过去这么多年我对于动物智力对比人类智力的言论————“大象/黑猩猩/海豚/边牧的智力约等于人类 X 岁的小孩”————的不解也来源于此（或许是我的知识太浅薄，且我没有认真钻研过，但是截止到这一秒我还是不解的），每种动物都有自己的智慧，只是人类目前看来是世界上智慧的最高点，我们就以人类的智慧为度量衡去 measure 所有生物的智慧。假如“智能”是一个几乎无限度的函数，我们在无法保证人类是 global optima 的时候，就去做了“自己已经是在 global optima”（换句话说“人类已经是完美智能”）的这个 bold 的假设。这种体系在 LLM 出现后，我感觉也在崩塌：模型可以在数学竞赛上获得冠军，但却无法数出 strawberry 有几个 R，这说明 LLM 的智力到底在人类的几岁呢？

在最后，stay humble，keep thinking，下一次就去写“活着”和“LLM 毁灭世界”的主题吧。

## 问答：何为智能？

本文首次发表于 Hub 平台作者：安妮卡・韦德尔（Annika Weder），2020 年 5 月 10 日刊载于《基础原理》——2020 年 10 月《基础原理》期刊

尽管短期内我们或许难以见到像《终结者》或《我，机器人》等电影中那样的超级智能计算机或机器人，但李大衍（Daeyeol Lee）认为，研究人类智能与人工智能之间的差异，有助于我们更好地理解技术的未来以及人类与技术的关系。

李大衍表示：“人类终有一天或许能创造出可自主物理复制的人工生命，唯有届时，我们才算真正创造出了人工智能。在此之前，机器永远都只是人类智能的‘替代品’，遗憾的是，这仍为控制人工智能的人留下了滥用的可能。”

在他的新书《智能的诞生》（牛津大学出版社，2020 年）中，李大衍追溯了大脑与智能的演化历程 —— 从自我复制的核糖核酸（RNA），到不同的动物物种、人类，甚至延伸至计算机，旨在解答关于智能起源、发展与局限的根本性问题。

李大衍是彭博神经经济学杰出教授，同时任职于克里格文理学院与医学院。与他的多数研究一致，《智能的诞生》具有高度的跨学科属性，应用并整合了神经科学、经济学、心理学、演化生物学及人工智能等多个领域的知识与工具。Hub 平台就其新书及决策、学习与认知的神经机制，对李大衍进行了专访。

## 智能是如何演化的？为何会演化出智能？

智能可定义为**解决复杂问题或做出能为行为主体带来有益结果的决策的能力**。在生命体中，智能的演化是为了适应多样的环境，以实现生存与繁衍。对动物而言，问题解决与决策能力是其神经系统（包括大脑）的功能，因此智能与神经系统密切相关。

## 您的著作与您多数研究一样，采用了高度跨学科的视角。演化视角如何帮助我们理解智能？

智能的定义颇具难度，不同人对其的理解也可能不同。然而，当我们从演化视角审视智能的起源与功能时，会浮现出几个重要原则。例如，不同生命体可能拥有截然不同的智能类型 —— 因为它们的演化根源不同，且适应了不同的环境。试图将不同动物物种置于线性的 “智能等级” 中排序（比如判断哪种犬类最聪明，或比较猫与狗谁更聪明），既具误导性，也毫无意义。更重要的是去理解：某一物种的特定智能形式是如何演化而来的，以及这种智能如何体现在该物种的解剖结构与生理机能中。

## 同样地，您运用了源自经济学的理论与概念。这些理论对理解智能有何帮助？

由于智能涵盖诸多层面，整合不同学科的见解与工具，对于更全面地理解 “智能究竟是什么”、厘清 “人工智能与人类智能的差异”，确实大有裨益。例如，经济学家已开发出精准的决策数学模型，如 “效用理论”—— 该理论基于某一选项或行为的 “效用”（即价值或合意性）来预测决策过程。凭借这些模型，我们只需通过少数假设，就能解释市场等复杂行为。这类 “简洁的决策模型” 对理解智能十分关键，因为决策本身就是智能的核心组成部分。其他极具价值的例子还包括 “委托 – 代理理论” 与 “博弈论”：将 “委托 – 代理理论” 应用于智能演化，可解释为何 “学习” 会成为解决大脑与基因之间利益冲突的方案；而 “博弈论” 则在解释 “为何在社会环境中做出优质决策颇具挑战性” 方面，发挥着关键作用。

## 人工智能终有一天会超越人类智能吗？人类智能是否存在某种无法复制的独特性？人类智能存在的某些限制，是否是计算机所没有的？

在围棋、扑克等诸多单一领域，人工智能已稳步超越人类智能。这一突破让部分研究者推测，“在所有领域都超越人类智能的人工智能” 即将出现 —— 这一假设性事件被称为 “技术奇点”。这类人工智能通常被称为 “通用人工智能”（AGI）或 “超级智能”。目前无人能确切知晓，人类是否能创造出通用人工智能或超级智能，以及何时能实现。

但在我看来，**真正的智能需要以 “生命” 为前提，而生命可定义为一个自我复制的过程**。因此，我认为超级智能要么无法实现，要么需等到极为遥远的未来。真正的智能应促进（而非阻碍）那些孕育它的基因的复制，这其中也包括大脑等必要的 “硬件”。若缺乏这一约束，我们便没有客观标准来判断某一解决方案是否具备 “智能”。

人类或许终有一天能创造出可自主物理复制的人工生命，唯有届时，我们才算真正创造出人工智能，但这在短期内几乎不可能实现。在此之前，机器永远都只是人类智能的 “替代品”，遗憾的是，这仍为控制人工智能的人留下了滥用的可能。

## 除了 “自我复制” 这一前提，为何创造超越人类智能的人工智能如此困难？

真正的智能需要生命体利用所处环境中可获取的能量及其他物理资源，去解决在多样环境中面临的各类问题。人类及许多其他动物的智能之所以令人惊叹，不仅在于它们能识别复杂物体、做出灵活行为，更在于它们能在如此多样的环境中，以如此多样的方式完成这些任务。目前，我们对人类与动物究竟如何实现这一点，仍知之甚少。

鉴于过去一个世纪神经科学研究的进展为当前人工智能技术的发展提供了助力，要创造更先进的人工智能，或许需要更深入地理解人类大脑是如何处理这类复杂任务的。

## 即便人工智能超越了人类智能，我们能察觉吗？

尽管我认为短期内这一情况不会发生，但我相信，若真有那么一天，我们一定能察觉。届时，我们可能会看到类似《终结者》中的机器 —— 因为拥有超级智能的机器，在获取自身维修与复制所需的能量及其他资源时，会比人类更具竞争力。

## 人工智能可能会对人机关系，乃至整个人类文明产生怎样的影响？

功能日益强大的人工智能，以及配备这类人工智能的机器，将持续发展，这无疑会提高控制这些工具的人的生产力。尽管生产力提升是好事，但这一过程在社会中的推进将是不均衡的，进而加剧业已存在的财富不平等。我认为这是人类历史上多次见证过的现象。

如何让社会全体成员公平地分享技术进步的成果，向来是比技术研发本身更难解决的问题，而我们也常常未能找到让所有人都满意的解决方案。要真正从技术进步中最大程度获益，我们还需认清技术的局限性及其被滥用的潜在风险。随着人类智能与人工智能之间的差距不断缩小，对这些问题的反思以及对解决方案的探索，甚至可能为我们提供一个更深入理解人性的契机。
